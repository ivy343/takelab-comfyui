# 워크플로 파일

`camera-api.json`은 두 PC에서 실제 실행한 기본 카메라 그래프의 API 형식 템플릿입니다. 입력 이미지 이름만 `takelab-example.png`라는 자리표시자로 바꿨습니다. 해당 이름의 이용 가능한 이미지를 자신의 Comfy input에 넣거나, `1.inputs.image`를 실제 입력 이름으로 바꿔 `/prompt`의 `prompt` 필드로 제출할 수 있습니다.

이 파일은 ComfyUI 화면 배치용 UI JSON이 아닌 실행 API 그래프입니다. 앱에서 **실행 워크플로**를 저장하면 해당 테이크에 실제 제출한 이미지 이름과 설정이 담긴 API 그래프를 받습니다. 레시피만 받아 실행하려면 동일한 입력 이미지가 별도로 필요합니다.

기본 경로는 모델 없이 CPU 카메라 합성만 수행합니다. SDXL 룩 생성 그래프는 `server.mjs`의 `makeWorkflow()`에 있으며 별도 미검증 실험입니다.
